¿Qué estamos comprobando?

Esta es la vista de pruebas del formulario de CLAN CARTAN. No es un alta de usuario real.

Sin conexión a Supabase. No hay registros, depósitos, modificaciones de usuarios ni mensajes enviados.
  1. El botón de registro comienza deshabilitado.
  2. Se habilita al aceptar términos y tratamiento de datos necesarios.
  3. La casilla de publicidad permanece opcional y no controla el registro.
  4. Se verifican correo, contraseña, documento, teléfono y ubicación al pulsar Registrar.
  5. No se guardan los datos escritos, incluso si la validación tiene éxito.

Seguridad: utiliza únicamente datos inventados para probar. No introduzcas contraseñas reales.

La autenticación real, verificación de correo y registro de consentimiento en Supabase se validarán con una base de pruebas independiente antes de activar esta versión.
