Correos autorizados para entregas comerciales

STREAM BULL’S permite que un proveedor conecte un buzón exclusivo para entregar licencias y códigos comerciales a los compradores de sus propios pedidos vigentes.

Autorización oficial y permisos

La conexión se realiza mediante OAuth de Google o Microsoft. CLAN CARTAN no solicita ni almacena contraseñas de Gmail u Outlook. Se solicitan permisos delegados de lectura y los necesarios para identificar y mantener la conexión del buzón autorizado. Como estos proveedores no limitan esos permisos a un único mensaje, debe utilizarse un buzón dedicado a entregas comerciales, sin información personal ajena a ese fin.

Qué se consulta

El sistema busca mensajes del remitente comercial configurado, con un asunto exacto que incluye el ORD y una plantilla de entrega que identifica la cuenta y la caducidad. No lee carpetas personales para otros fines, no descarga adjuntos ni ofrece acceso general al buzón. No redistribuye contraseñas, semillas de autenticador, códigos de inicio de sesión, recuperación o doble factor de plataformas de terceros.

Qué recibe el comprador

El comprador debe iniciar sesión y ser titular del pedido. Solo recibe el código comercial autorizado que corresponde a la cuenta asignada, mientras el pedido y el código estén vigentes. No recibe tokens OAuth, correos completos, mensajes del buzón ni información de otras cuentas.

Notificaciones de depósitos de ADMIN

ADMIN puede autorizar un buzón para detectar avisos de depósitos con los mismos proveedores OAuth. El consentimiento permite lectura del buzón; la aplicación restringe sus consultas al Inbox, remitentes exactos configurados y un intervalo reciente. Se recomienda un buzón dedicado. Solo ADMIN accede a la conciliación, separada de las conexiones de proveedores y de los pedidos ORD.

Se conservan identificador del mensaje, remitente, asunto limitado, fecha, indicador de autenticación y posibles importes o referencias para revisión. No se guardan cuerpos completos ni adjuntos. Estos datos no confirman un pago y nunca acreditan dinero por sí solos. Los avisos se conservan para trazabilidad y podrán ser objeto de solicitudes de privacidad, respetando las obligaciones legales de conservación.

Protección y conservación

Los tokens y recursos de entrega se protegen mediante el almacenamiento cifrado de Supabase Vault y servicios del backend. Se comprueban titularidad, estado, vigencia y asignación en el servidor. Se registran las consultas y se aplican límites de uso. El historial comercial del pedido se conserva; los recursos caducados dejan de entregarse. Los tokens del buzón se eliminan del almacenamiento de la conexión al desconectarlo.

Desconectar y revocar

El proveedor puede desconectar el buzón desde «Mis correos». Esto bloquea nuevas lecturas y consultas automáticas para sus cuentas vinculadas. También puede revocar el permiso en su cuenta de Google o en su cuenta de Microsoft. Microsoft puede requerir la retirada del consentimiento desde el portal de la organización.

Uso limitado

El uso y la transferencia de información obtenida mediante las API de Google se ajustan a la Política de Datos de Usuario de los Servicios API de Google, incluidos sus requisitos de Uso Limitado. No se utilizan datos del correo para publicidad, perfilado, venta de datos o entrenamiento de modelos.
